Códigos de Arduino, Python y Matlab

Codigos de arduino, definen los roles de cada ESP: (Tranmisor, Receptor) e interferencia del nodo C (en protocolos: ESP-NOW y TCP/IP).
Código Python: Para visualización en vivo de los datos tomados a partir del puerto serial.
Codigo MATLAB: Tres experimentos donde se toman y evaluan los datos el puerto serie en un script de toma-pausa-toma. Con ellos se pueden graficar y analizar los datos obtenidos.
